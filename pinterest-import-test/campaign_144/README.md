# 144 пина: 21 октября — 31 декабря 2026

Основной файл: **`pinterest_144_2026-10-21_to_2026-12-31.csv`**. Он предназначен для того же массового CSV-загрузчика Pinterest, в котором успешно разместились два тестовых пина. Скачивайте файл кнопкой **Download raw file**, не сохраняйте HTML-страницу просмотра GitHub вместо CSV.

## Период и количество

- 72 дня включительно: с 21 октября по 31 декабря 2026.
- 2 разных пина ежедневно: **12:00 и 19:00, Asia/Yakutsk (UTC+9)**.
- В поле `Publish date` указано время UTC: **03:00 и 10:00**, формат `YYYY-MM-DDTHH:MM:SS`.
- 144 будущие публикации: 118 из прежнего набора + 26 новых пинов.
- Два уже опубликованных теста исключены: `new_006` (куриные котлеты для заморозки) и `ref_001` (гречка по-купечески).
- По **24 публикации на каждую из шести досок**. Названия досок сохранены точно.
- Праздничная серия распределена с **20 ноября по 31 декабря**, к Новому году 2027.

## Схема, которая сработала

`Title,Media URL,Pinterest board,Thumbnail,Description,Link,Publish date,Keywords`

Кодировка UTF-8 с BOM, разделитель-запятая, все поля в двойных кавычках, переносы LF. Заголовок побайтно совпадает с заголовком успешно загружавшегося файла `zavtraki-bulk-upload.csv`. `Thumbnail` пустой для PNG. Пустых дат публикации в этой очереди нет.

Все изображения размещены в отдельной ветке публичного репозитория `expert-platform-v1`, на том же хостинге, который успешно сработал в тесте. Итоговые ссылки закреплены за коммитом с полным комплектом изображений, чтобы последующие правки ветки не меняли файлы в очереди. CSV содержит прямые ссылки на PNG, а не страницы просмотра GitHub. Не удаляйте эту ветку до завершения загрузок.

В каждом пине есть заголовок, SEO-описание, связанные ключевые запросы и призыв купить готовое меню. Целевая ссылка ведёт на `https://menu-gamma-navy-77.vercel.app/` с уникальной UTM-меткой. Кампания: `dasha_menu_oct_dec_2026`.

## Как загружать

1. Пользуйтесь только этой новой очередью. Прежние CSV на 120 пинов и тестовые файлы не загружайте вместе с ней: они содержат пересекающиеся публикации.
2. Если Pinterest принимает полный период и объём — загрузите основной CSV один раз. Фактическое принятие полного календаря конкретным аккаунтом ещё не проверялось.
3. Если загрузчик ограничивает дальние даты или число запланированных пинов, используйте файлы из `batches/`: они содержат те же строки, разбитые по неделям. Размер партии — удобство, не утверждение о лимите Pinterest.
4. Не загружайте одновременно основной CSV и партии: это создаст дубли. Повторно отправляйте только строки, которые Pinterest явно отклонил.
5. Проверяйте результат обработки загрузки и первое время публикации. Массовая обработка может занимать время; мгновенное появление в интерфейсе не гарантируется.

## Файлы

- `pinterest_144_2026-10-21_to_2026-12-31.csv`: полный импортный CSV.
- `batches/`: недельные партии, вместе составляющие ровно тот же календарь из 144 строк.
- `calendar_excel_ru.csv`: редакционная таблица с временем по Якутску, alt-текстами, SEO и ссылками. Для просмотра, не для импорта.
- `manifest.json`: полные данные очереди.
- `media_check.csv`: проверка доступности PNG по HEAD и GET и совпадения скачанных изображений с оригиналами.
- `VALIDATION.json`: результаты проверки дат, количества, исключения тестов и распределения по доскам.
