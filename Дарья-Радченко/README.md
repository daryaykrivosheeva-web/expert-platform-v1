# Дарья Радченко — сайт студии

Это твой сайт: разработка сайтов и цифровых инструментов для экспертов и
малого бизнеса. Один проект, один сайт — без переключателей между другими
клиентами.

## Как редактировать текст

Весь контент сайта (заголовки, услуги, портфолио, контакты, цены,
юридические данные) — в одном файле:

```
src/config/site-content.ts
```

Меняешь текст в этом файле → сохраняешь → сайт обновляется. Компоненты
(вёрстку, анимации) трогать не нужно.

В начале файла — список данных-заглушек, которые стоит заменить перед
реальным запуском (домен сайта, ссылка на MAX, отчество для юридических
документов).

## Фото

Положи файлы в `public/images/` (например `public/images/hero.jpg`) и
укажи путь в `site-content.ts`:

- `hero.image` — фото на главном экране
- `about.photo` — фото в разделе «Обо мне»
- `expert.photo` — запасной вариант, если два поля выше не заполнены

Если фото не указано, вместо него показывается аккуратный градиент с
твоими инициалами — сайт не «ломается» без фото.

## Локальный запуск

```bash
npm install
npm run dev
```

Другие команды:

```bash
npm run build      # финальная сборка
npm run start       # запуск собранной версии
npm run lint         # проверка кода
npm run typecheck    # проверка типов
```

## Деплой на Vercel

1. Vercel → New Project → Import Git Repository → этот репозиторий
   (`daryaykrivosheeva-web/expert-platform-v1`)
2. **Root Directory**: `Дарья-Радченко` (именно эта папка)
3. Больше ничего настраивать не нужно — никаких переменных окружения,
   никаких дополнительных полей. Framework (Next.js) определится сам.
4. Deploy

## Деплой на Netlify

То же самое: указать **Base directory** = `Дарья-Радченко`, всё остальное
уже настроено в `netlify.toml`.

## Юридические страницы

Формируются автоматически из `legal` в `site-content.ts`:

- `/legal/privacy` — политика конфиденциальности
- `/legal/consent` — согласие на обработку данных
- `/legal/terms` — условия использования
- `/legal/cookies` — политика cookie
- `/legal/requisites` — реквизиты

## Стек

Next.js 16 + React + TypeScript + Tailwind CSS + Framer Motion. Ничего
дополнительно устанавливать не нужно, кроме `npm install`.

## Как это соотносится с папкой `Сайт/`

`Сайт/` — это общий шаблон, на основе которого делаются сайты для клиентов
студии (психолог, юрист и т.д.), переключение между ними — через
переменную окружения. Эта папка (`Дарья-Радченко/`) — самостоятельная
копия того же кода, но настроенная на один-единственный сайт, без
переключателей, чтобы деплой был максимально простым. Если в `Сайт/`
позже поправят какой-то общий компонент (например дизайн кнопки), в этой
папке автоматически это не появится — нужно будет попросить перенести
изменение сюда вручную.
