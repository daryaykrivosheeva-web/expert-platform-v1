# Прогрев — лендинг продукта «5 готовых инструментов»

Самостоятельный статический сайт (без сборки, без npm) — три HTML-страницы
и один файл стилей. Не связан с `Сайт/` (шаблон для клиентов) и `my/`
(сайт студии) — это отдельный продающий лендинг под конкретный цифровой
продукт Даши.

## Файлы

- `index.html` — сам лендинг: hero, лид-магнит, «почему я это сделала»,
  «проблема», «что внутри» (5 инструментов), блок с ценой, футер.
- `policy.html` — Политика конфиденциальности.
- `consent.html` — Согласие на обработку персональных данных (152-ФЗ).
- `style.css` — общие стили (светлая зелёно-тиловая палитра).

## Что нужно донастроить перед запуском

1. **Кнопка оплаты.** Сейчас это заглушка: `<a href="#" class="buy-button">`
   (на первой кнопке ещё есть `id="buy-button"`). В `index.html` таких
   кнопок две (hero и блок с ценой) — у обеих класс `buy-button`. Замени
   `href="#"` на ссылку на оплату в обоих местах.
2. **Email для связи.** В `policy.html` и `consent.html` стоит плейсхолдер
   `[укажи email для связи]` в разделе «Контакты» — впиши реальный адрес.
3. **Ссылка на лид-магнит** (бесплатный чек-лист в Notion) уже вшита в
   кнопку «Забрать бесплатный чек-лист» на главной странице.

## Локальный просмотр

Открыть `index.html` в браузере напрямую, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и зайти на `http://localhost:8000`.

## Деплой

Статический сайт — подходит любой хостинг (Vercel, Netlify, GitHub
Pages и т.д.) без настройки сборки. Для Vercel/Netlify: Root/Base
directory = `Прогрев`, Build command — пусто, Output directory —
корень папки.
