# Прогрев — лендинг продукта «5 готовых инструментов»

Next.js 16 + TypeScript + Tailwind CSS + Framer Motion — тот же стек, что
у `Сайт/` и `my/` в этом репозитории, готовый к деплою на Vercel. Не
связан с `Сайт/` (шаблон для клиентов) и `my/` (сайт студии) — это
отдельный продающий лендинг под конкретный цифровой продукт Даши.

## Структура

- `src/app/page.tsx` — главная: hero, лид-магнит, «почему я это сделала»,
  «проблема», «что внутри» (5 инструментов), блок с ценой.
- `src/app/legal/policy/page.tsx` — Политика конфиденциальности.
- `src/app/legal/consent/page.tsx` — Согласие на обработку персональных
  данных (152-ФЗ).
- `src/content/site-content.ts` — весь текст сайта в одном месте (заголовки,
  описания инструментов, цена, ссылки). Правки текста — сюда, компоненты
  трогать не нужно.
- `src/content/legal-content.ts` — текст юридических страниц + реквизиты.
- `src/components/` — секции страницы и UI-примитивы (`Button`, `Container`,
  `Reveal` — анимация появления блоков при скролле).

## Анимация

Блоки плавно появляются при скролле (Framer Motion `whileInView`). На
случай резкого перехода (клик по якорю, мгновенный скролл), когда блок
может проскочить мимо области видимости, стоит защитный таймер: если
блок не показался сам за 2 секунды — он появляется принудительно. Это
проверено: полная страница остаётся полностью читаемой даже без единого
скролла.

## Локальный запуск

```bash
npm install
npm run dev
```

Другие команды:

```bash
npm run build      # финальная сборка
npm run start       # запуск собранной версии
npm run lint         # проверка кода
npm run typecheck    # проверка типов
```

## Деплой на Vercel

1. Vercel → New Project → Import Git Repository → этот репозиторий
2. **Root Directory**: `Прогрев`
3. Framework (Next.js) определится сам, остальное настраивать не нужно
4. Deploy
